# Pole Position

Turn a plain Power BI report into a designed, interactive dashboard. A 90-minute hands-on session by **Ribesh Maharjan**, using 76 seasons of Formula 1 data.

**[Open the lecture](https://ribesh19.github.io/f1/)** · **[Open the workbook](https://ribesh19.github.io/f1/workbook.html)** · **[Download everything (zip)](https://github.com/Ribesh19/f1/archive/refs/heads/main.zip)**

## Start here

1. Download the zip, unzip it and open `powerbi/Starter.pbix` in Power BI Desktop.
2. Open [workbook.html](workbook.html) in a browser and follow the laps. Every click is written out, with a picture of what you should see.

| Lap | You do | Stuck? Open |
|---|---|---|
| 1 | Import a theme and three backgrounds | `powerbi/Lap-1.pbix` |
| 2 | Swap a table, a pie and a donut for the right charts | `powerbi/Lap-2.pbix` |
| 3 | Write a headline and turn three totals into story numbers | `powerbi/Lap-3.pbix` |
| 4 | Let measures pick the colour and write the title | `powerbi/Lap-4.pbix` |
| 5 | Build a tooltip page and an animated chart | `powerbi/Lap-5.pbix` |
| 6, 7 | Drill-through and bookmarks, in your own time | `powerbi/Finished.pbix` |

## What is in the box

| Folder | Contents |
|---|---|
| `powerbi/` | Starter, a checkpoint after each lap, Finished, and a Gallery of five styles |
| `design/` | Theme file, backgrounds (PNG, SVG, PowerPoint), [Figma steps](design/FIGMA.md) |
| `guides/`, `data/` | [Make your own background](guides/backgrounds.md), [all measures](guides/measures.dax), the six CSV tables behind the model |

Nothing to install, no sign-in, no refresh: the data is inside each file. Written for Power BI Desktop, October 2026.
