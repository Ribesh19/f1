# Open the backgrounds in Figma

There is no shared Figma file. Each background is an SVG that Figma opens as editable layers.

1. In Figma, create a new design file.
2. Drag any `.svg` from `design/backgrounds/` onto the canvas.
3. You get a 1280 x 720 frame with named layers: the rail, each panel, the photo and the icons.

Edit the layers, then select the frame and choose **Export** > **PNG** at **2x**.

The same designs, built from PowerPoint shapes, are in `Backgrounds.pptx`.
