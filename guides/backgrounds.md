# Make your own dashboard background

A background holds the structure: panels, bands and dividers. Numbers and labels stay in Power BI.

## In PowerPoint

1. Open `design/Backgrounds.pptx`. Each slide is one background made of plain shapes.
2. Move, resize or recolour any shape. Slide size is 13.333 in x 7.5 in (1280 x 720).
3. **File** > **Export** > **Change File Type** > **PNG** > **Save As** > **Just This One**.

## In Figma

1. In Figma, create a new file and drag any `.svg` from `design/backgrounds/` into it.
2. Edit the rectangles in the 1280 x 720 frame.
3. Select the frame > **Export** > **PNG** at **2x**.

## Apply it in Power BI

1. Click an empty part of the canvas.
2. In **Visualizations**, click the **Format page** tab > **Canvas background** > **Image** > **Browse**.
3. Choose your PNG.
4. Set **Image fit** to **Fit** and **Transparency** to **0%**.

Tip: turn off each visual's own background so the panels show through. The theme file does this for you.
